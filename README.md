# 🪓 Hangman Word Guessing Game

An interactive, high-tension word deduction game built with Python and CustomTkinter. Features real-time rope pendulum physics, a textured red sketch aesthetic, an in-window modal architecture, and a strategic penalty-hint mechanic.

## ⚡ Key Highlights

- **Dynamic Pendulum Swing**: Utilizes real-time trigonometric harmonic oscillation to simulate natural rope momentum on the gallows.
- **Organic Red Sketch Figure**: Multi-stroke silhouette rendering inspired by dark hand-drawn ink illustrations rather than basic stick lines[cite: 2].
- **Unified Single-Window Interface**: Eliminates OS popups by managing Dev Profiles, Manuals, and Victory screens through stacked in-window modal frames.
- **High-Risk Hint System**: Instant letter discovery at the direct cost of +1 hang mistake (strictly capped at 3 uses per session).
- **Celebratory Victory Blast**: Renders a live multi-particle confetti explosion upon successfully cracking the hidden term.
- **Curated Engineering Vocabulary**: 25 preloaded computer science and software development terms equipped with descriptive clues.

---

## 🛠️ Tech Stack & Concepts

- **Language**: Python 3.8+
- **GUI Engine**: CustomTkinter
- **Vector Graphics & Physics**: Tkinter Canvas with trigonometric oscillation formulas (`math.sin`, vector rotations)
- **State Management**: Set-based character validation and dynamic UI state disabling
- **Web Integration**: Native `webbrowser` standard library for developer profile links
